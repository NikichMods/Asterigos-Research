# Asterigos Research — working contract

Этот репозиторий подчиняется [NikichMods/DevRules](https://github.com/NikichMods/DevRules). Начинать с `WORKING_RULES.md`; для инженерного исследования применять `ENGINEERING_RULES.md`, для Git — `GIT_WORKFLOW.md`, для локального Codex — `CODEX_WORKFLOW.md`.

## Назначение

- Цель: единый источник **повторно используемых знаний** об Asterigos: Curse of the Stars для исследований и отдельных модов NikichMods.
- Объект: PC-версия игры; один принятый baseline **Steam 1.09 / build 12996889, UE4.27, Windows x64** задокументирован в [AsterigosMods](https://github.com/NikichMods/AsterigosMods). Отдельные DLC, магазины и другие сборки нельзя считать подтверждёнными автоматически. См. [верифицированные данные](docs/VERIFIED_RUNTIME.md).
- Этот репозиторий не владеет поведением ни одного выпущенного мода, его версией, релизом, поддержкой или приёмкой. Такие сведения принадлежат репозиторию самого мода.
- `main` — актуальные канонические исследовательские документы. Документальные изменения без изменения runtime могут попадать прямо в `main` по DevRules.

## Уровни доказательств

- **Патч/официальное сообщение**: разработчик заявил о внедрении или исправлении. Не означает, что оно проверено в текущем установленном билде.
- **Наблюдение пользователя**: пользователь сообщил о поведении своей игры. Не превращать автоматически в универсальный факт.
- **Сообщение сообщества**: свидетельство конкретного игрока/обсуждения, включая противоположные мнения. Не заявлять массовость без подсчёта.
- **Технически подтверждено**: конкретная версия, проверенный объект/механизм, воспроизводимая процедура и результат.
- **Гипотеза / идея**: проектное предложение без технического доказательства. Не смешивать с готовой реализацией.

Перед новым исследованием сначала искать применимые выводы здесь, затем в документах и истории соответствующего мода. При подтверждении механизма записывать: версию игры; объект/путь-владелец; финальный потребитель/писатель; наблюдаемый результат; источник/тест; ограничения и затронутые моды. Не публиковать чужие ассеты, большие выгрузки декомпиляции и секреты.

## Специальные решения по масштабу

- Предпочтение: узкие изменения понятности интерфейса, читаемости боя, локального баланса и доступности вместо полного редизайна уровня, ИИ, сюжета или состава врагов.
- Не объявлять задачу простой только потому, что для результата достаточно нарисовать текст или изменить число: сначала установить реального владельца поведения.
- Динамический HUD имеет проверенного владельца: компонент [CombatHUD](https://github.com/NikichMods/AsterigosMods/tree/main/CombatHUD) исходного `AsterigosMods`; канонический статус и принятый релиз указаны в его `docs/STATUS.md`, а не здесь. При разделении монорепозитория обновить ссылку на новый модовый репозиторий, сохранив исходные доказательства. Не включать повторную реализацию в новые идеи.
- Не переносить эту исследовательскую оценку в утверждение, что мод технически реализуем, пока не получены игровые/инструментальные доказательства.
